
# Flujo Completo: Desde la Compra del QR hasta el Perfil Público

## 1. Compra del QR

### 1.1 Crear una Orden de Compra
- **Método**: `POST`
- **URL**: `http://localhost:5000/api/orders`
- **Headers**: 
  ```
  Authorization: Bearer {token}
  Content-Type: application/json
  ```
- **Body**:
  ```json
  {
    "quantity": 1,
    "shippingDetails": {
      "address": "Calle Principal 123",
      "city": "Ciudad Ejemplo",
      "state": "Estado Ejemplo",
      "zipCode": "12345",
      "country": "País Ejemplo"
    }
  }
  ```
- **Respuesta Esperada**:
  ```json
  {
    "success": true,
    "order": {
      "_id": "60d21b4667d0d8992e610c85",
      "userId": "60d21b4667d0d8992e610c84",
      "quantity": 1,
      "totalAmount": 10,
      "status": "pending",
      "paymentId": "payment_1741648353520",
      "shippingDetails": {
        "address": "Calle Principal 123",
        "city": "Ciudad Ejemplo",
        "state": "Estado Ejemplo",
        "zipCode": "12345",
        "country": "País Ejemplo"
      },
      "createdAt": "2023-09-15T12:00:00.000Z"
    },
    "clientSecret": "client_secret_1741648353546"
  }
  ```

## 2. Registro de Mascota

### 2.1 Crear una Mascota
- **Método**: `POST`
- **URL**: `http://localhost:5000/api/pets`
- **Headers**: 
  ```
  Authorization: Bearer {token}
  Content-Type: application/json
  ```
- **Body**:
  ```json
  {
    "name": "Firulais",
    "species": "Perro",
    "breed": "Labrador",
    "age": 3,
    "color": "Dorado",
    "description": "Perro muy amigable y juguetón",
    "medicalInfo": "Vacunas al día, castrado"
  }
  ```
- **Respuesta Esperada**:
  ```json
  {
    "success": true,
    "pet": {
      "_id": "60d21b4667d0d8992e610c87",
      "name": "Firulais",
      "species": "Perro",
      "breed": "Labrador",
      "age": 3,
      "color": "Dorado",
      "description": "Perro muy amigable y juguetón",
      "medicalInfo": "Vacunas al día, castrado",
      "owner": "60d21b4667d0d8992e610c84",
      "createdAt": "2023-09-15T12:10:00.000Z"
    }
  }
  ```

## 5. Comunicación con el Dueño

### 5.1 Enviar Mensaje al Dueño (Usuario Autenticado)
- **Método**: `POST`
- **URL**: `http://localhost:5000/api/messages/pet/60d21b4667d0d8992e610c87`
- **Headers**: 
  ```
  Authorization: Bearer {token}
  Content-Type: application/json
  ```
- **Body**:
  ```json
  {
    "subject": "Encontré a tu mascota",
    "content": "Hola, encontré a Firulais en el parque. Está bien y lo tengo conmigo.",
    "location": {
      "latitude": 40.7128,
      "longitude": -74.0060,
      "address": "Central Park, New York"
    }
  }
  ```
- **Respuesta Esperada**:
  ```json
  {
    "success": true,
    "message": "Mensaje enviado correctamente al dueño de la mascota"
  }
  ```

## 6. Gestión de Mascota Perdida (Opcional)

### 6.1 Reportar Mascota como Perdida
- **Método**: `POST`
- **URL**: `http://localhost:5000/api/pets/60d21b4667d0d8992e610c87/lost`
- **Headers**: 
  ```
  Authorization: Bearer {token}
  Content-Type: application/json
  ```
- **Body**:
  ```json
  {
    "location": {
      "latitude": 40.7128,
      "longitude": -74.0060,
      "address": "Central Park, New York"
    }
  }
  ```
- **Respuesta Esperada**:
  ```json
  {
    "success": true,
    "pet": {
      "_id": "60d21b4667d0d8992e610c87",
      "isLost": true,
      "lastSeenLocation": {
        "latitude": 40.7128,
        "longitude": -74.0060,
        "address": "Central Park, New York"
      },
      "lostDate": "2023-09-15T14:30:00.000Z"
    },
    "message": "Mascota reportada como perdida"
  }
  ```

### 6.2 Reportar Mascota como Encontrada
- **Método**: `POST`
- **URL**: `http://localhost:5000/api/pets/60d21b4667d0d8992e610c87/found`
- **Headers**: 
  ```
  Authorization: Bearer {token}
  ```
- **Respuesta Esperada**:
  ```json
  {
    "success": true,
    "pet": {
      "_id": "60d21b4667d0d8992e610c87",
      "isLost": false,
      "lastSeenLocation": null,
      "lostDate": null
    },
    "message": "Mascota reportada como encontrada"
  }
  ```

## Resumen del Flujo

1. **Compra del QR**:
   - El usuario crea una orden de compra
   - Confirma el pago
   - Recibe uno o más códigos QR

2. **Registro de Mascota**:
   - El usuario registra una mascota
   - Opcionalmente añade fotos

3. **Vinculación del QR**:
   - El usuario vincula un QR a su mascota
   - El QR queda permanentemente asociado a esa mascota

4. **Escaneo del QR**:
   - Cualquier persona puede escanear el QR
   - El sistema detecta si el usuario está autenticado
   - Se muestra el perfil público de la mascota

5. **Comunicación con el Dueño**:
   - Si el usuario está autenticado, puede enviar un mensaje directamente
   - Si no está autenticado, debe proporcionar nombre y email
   - El dueño recibe el mensaje y puede responder

6. **Gestión de Mascota Perdida** (opcional):
   - El dueño puede marcar la mascota como perdida
   - Puede proporcionar la última ubicación conocida
   - Cuando la mascota es encontrada, puede marcarla como tal

Este flujo completo permite una experiencia integral desde la compra del QR hasta la comunicación entre quien encuentra una mascota y su dueño, facilitando la recuperación de mascotas perdidas.
